┌───────────────────────────────────────────────────────────────────────────┐
│                         🎯 PROJECT OVERVIEW                               │
└───────────────────────────────────────────────────────────────────────────┘

ELEVARE is a production-grade AI-powered career discovery platform that uses
longitudinal behavioral analysis to provide personalized career recommendations.

Unlike traditional career tests, ELEVARE interacts with users daily over 
weeks/months to build comprehensive behavioral and personality profiles.

┌───────────────────────────────────────────────────────────────────────────┐
│                         ✨ KEY FEATURES                                   │
└───────────────────────────────────────────────────────────────────────────┘

  🤖 Daily AI Conversations        📊 Behavioral Analysis
  🧠 Personality Profiling         🎯 Ikigai Framework
  💡 Career Recommendations        📈 Interactive Dashboard
  🔐 Secure Authentication         🚀 Production Ready

┌───────────────────────────────────────────────────────────────────────────┐
│                         🛠️ TECHNOLOGY STACK                               │
└───────────────────────────────────────────────────────────────────────────┘

  Frontend:  React 18 + Vite + TailwindCSS + Recharts
  Backend:   Node.js + Express + MongoDB + JWT
  AI:        Python + FastAPI + Transformers + Scikit-learn
  NLP:       DistilRoBERTa + NLTK + TextBlob

┌───────────────────────────────────────────────────────────────────────────┐
│                         ⚡ QUICK START                                    │
└───────────────────────────────────────────────────────────────────────────┘

  Windows Users:
    1. Run: setup.bat
    2. Run: start-all.bat
    3. Open: http://localhost:3000

  Manual Setup:
    1. Install: Node.js 18+, Python 3.9+, MongoDB 6+
    2. Setup Backend:    cd backend && npm install && npm run dev
    3. Setup Frontend:   cd frontend && npm install && npm run dev
    4. Setup AI:         cd ai-services && pip install -r requirements.txt && python main.py
    5. Start MongoDB:    mongod --dbpath ./data/db
